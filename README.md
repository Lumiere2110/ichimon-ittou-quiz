# 一問一答クイズ

自分で登録した問題で遊ぶ、一問一答形式のクイズゲームです。HTML ファイル 1 つで動きます。

**遊ぶ：** https://lumiere2110.github.io/ichimon-ittou-quiz/

## できること

- **問題の登録**：ジャンル › カテゴリ › サブカテゴリ の 3 階層で分類して登録。別解は `/` で区切ります。
- **答えが複数ある問題**：答え欄に 1 行 1 つずつ書くと、「世界三大珍味を答えよ」のように答えを複数入力する問題になります（順不同／順番どおりを選べます）。
- **画像**：問題に画像を付けられます（ファイルを選ぶか貼り付け）。
- **まとめて追加**：1 行に 1 問、`ジャンル>カテゴリ>サブカテゴリ,難易度(1〜3),問題文,答え` の形で一括登録。答えが複数ある問題は答え同士を `|` で区切ります。
- **ゲーム設定**：出題範囲（総合／ジャンル／カテゴリ／サブカテゴリ）、難易度、1 問あたりの制限時間、問題数、出題順。
- **判定**：ひらがな／カタカナ、全角／半角、大文字／小文字、空白の違いを無視する設定あり。
- **結果画面**：間違えた問題の一覧（答えは隠して表示）、暗記カードでの復習、間違えた問題だけの再挑戦、正解した問題の一覧。

## データの保存

問題はブラウザの localStorage に保存されます。保存先はそのブラウザだけなので、別の端末やブラウザとは共有されません。サイトデータを消すと問題も消えます。

## 収録問題

`questions.js` に収録問題が入っています。

- 情報・テクノロジー › 応用情報技術者試験 › ネットワーク：30 問
- 情報・テクノロジー › 写真・映像 › 撮影技法：1 問
- 科学・自然 › 健康・医療 › 検査：1 問
- 生活・雑学 › 暮らし › 日用品・身近な道具：1 問
- 生活・雑学 › 健康 › 心・感情：1 問
- 生活・雑学 › その他：10 問
- 生活・雑学 › 一般雑学 › 名前・由来：1 問
- 生活・雑学 › 言葉・考え方 › 哲学・意識問題：1 問

最初に開いたときに読み込まれます。あとから収録問題が増えたときは、新しい問題だけが自動で追加されます。自分で削除した収録問題は戻りません。収録問題の状態に戻したいときは、サイトデータを消してから開き直してください。

## ローカルで使う

`index.html` をブラウザで開くだけで動きます。
