# 一問一答クイズ

自分で登録した問題で遊ぶ、一問一答形式のクイズゲームです。HTML ファイル 1 つで動きます。

**遊ぶ：** https://lumiere2110.github.io/ichimon-ittou-quiz/

## できること

- **問題の登録**：ジャンル › カテゴリ › サブカテゴリ の 3 階層で分類して登録。別解は `/` で区切ります。
- **まとめて追加**：1 行に 1 問、`ジャンル>カテゴリ>サブカテゴリ,難易度(1〜3),問題文,答え` の形で一括登録。
- **ゲーム設定**：出題範囲（総合／ジャンル／カテゴリ／サブカテゴリ）、難易度、1 問あたりの制限時間、問題数、出題順。
- **判定**：ひらがな／カタカナ、全角／半角、大文字／小文字、空白の違いを無視する設定あり。
- **結果画面**：間違えた問題の一覧（答えは隠して表示）、暗記カードでの復習、間違えた問題だけの再挑戦。

## データの保存

問題はブラウザの localStorage に保存されます。保存先はそのブラウザだけなので、別の端末やブラウザとは共有されません。サイトデータを消すと問題も消えます。

## 収録問題

`questions.js` に、最初に開いたときに読み込まれる問題が入っています（情報・テクノロジー › 応用情報技術者試験 › ネットワーク 30 問）。一度でも問題を追加・編集・削除すると、それ以降はブラウザに保存した内容が使われます。収録問題の状態に戻したいときは、サイトデータを消してから開き直してください。

## ローカルで使う

`index.html` をブラウザで開くだけで動きます。
