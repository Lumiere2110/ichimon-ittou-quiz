# 一問一答クイズ

自分で登録した問題で遊ぶ、一問一答形式のクイズゲームです。HTML ファイル 1 つで動きます。

**遊ぶ：** https://lumiere2110.github.io/ichimon-ittou-quiz/

## できること

- **問題の登録**：ジャンル › カテゴリ › サブカテゴリ の 3 階層で分類して登録。分類はプルダウンで今ある名前から選べます（「＋ 新しく入力」で新しい名前も追加できます）。「＋ 分類を追加」で 1 つの問題を複数の分類に入れられます。別解は `/` で区切ります。
- **答えが複数ある問題**：答え欄に 1 行 1 つずつ書くと、「世界三大珍味を答えよ」のように答えを複数入力する問題になります（順不同／順番どおりを選べます）。
- **画像**：問題に画像を付けられます（ファイルを選ぶか貼り付け）。
- **まとめて追加**：1 行に 1 問、`ジャンル>カテゴリ>サブカテゴリ,難易度(1〜3),問題文,答え` の形で一括登録。答えが複数ある問題は答え同士を `|` で区切ります。複数の分類に入れるときは分類同士を `;` で区切ります。
- **ゲーム設定**：出題範囲（総合／ジャンル／カテゴリ／サブカテゴリ。「＋ 範囲に追加」で複数の範囲を混ぜて出題）、難易度、1 問あたりの制限時間、1 問で失敗できる回数（制限時間内ならその回数まで答え直せる）、間違えてもいい回数（ゲーム全体。超えるとゲームオーバー）、問題数、出題順。
- **判定**：ゆるく判定する設定あり。ひらがな／カタカナ、全角／半角、大文字／小文字、空白、記号（・ や - など）、「ー」、小さい文字（ァ・ッ など）の違いを無視し、1〜2 文字の打ち間違いも正解にします（数字を含む答えは除く）。答えが複数ある問題は、すべて合っているときだけ正解です。
- **パスのキー**：パスに使うキー（Esc や Ctrl+P など）を設定できます。設定はそのブラウザに保存されます。
- **結果画面**：間違えた問題の一覧（答えは隠して表示）、暗記カードでの復習、間違えた問題だけの再挑戦、正解した問題の一覧。

## データの保存

問題はブラウザの localStorage に保存されます。保存先はそのブラウザだけなので、別の端末やブラウザとは共有されません。サイトデータを消すと問題も消えます。
